# Cover concept — Legis24

## Brand style

- **Primary color:** #1e40af (тёмно-синий)
- **Accent:** белый, золотистый
- **Mood:** строгий, деловой, профессиональный
- **Language:** все надписи на РУССКОМ языке
- **Elements:** документы с печатями, лупа, НК РФ, калькулятор, офисная обстановка

## Image rules

- Фотореалистичный стиль
- Соотношение 16:9
- Текст на изображениях — только на русском
- Без людей (или только руки/силуэты)
- Без мелкого нечитаемого текста
