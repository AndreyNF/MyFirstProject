## Ключевые факты (верифицированы)

1. **Продажа (крипта → рубли):** пользователь указывает сумму и банк; рубли приходят на счёт, привязанный к номеру телефона (migswap.com, fact-bank).
2. **Счёт и телефон:** счёт для рублей должен быть привязан к номеру, который указан при идентификации — требование платёжной системы (migswap.com FAQ, fact-bank).
3. **Идентификация:** разовая, ~2–3 минуты, по ссылке из бота; требование 115-ФЗ для операций с рублями; повторных проверок нет (fact-bank, migswap.com).
4. **СБП:** 200+ банков-участников; покупка — QR из приложения любого банка; продажа — зачисление по СБП (fact-bank).
5. **Покупка:** оплата QR по СБП из приложения банка; ссылка 5 минут; крипта на указанный кошелёк после оплаты (fact-bank).
6. **Официальный бот:** только @MigSwap_bot; сервис не пишет первым (fact-bank, site-brief).
7. **При ошибках:** опоздание — заявка истекает; средства на платёжной платформе, возврат через поддержку в боте (fact-bank).
