## Задача

По теме поста из `content/telegram/series/` или handoff Макса:

1. Составь **уникальный** промпт (сцена, объекты, настроение — не копировать Avito/другие посты)
2. MCP **`gpt-image-2`**: `aspect_ratio` 16:9, `resolution` 2K
3. Верни URL tempfile + строку для `wordpress_upload_media` (архив)
4. **Не** использовать старые URL без новой генерации
