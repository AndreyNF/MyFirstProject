# Skill: seo-writer-zhenya-avito-mode

Режим **Жени** для пайплайна Avito.

## Задача

Текст **описания объявления** с SEO-вкраплениями из ядра Коли и отстройкой от конкурентов Артёма.

## Вход

- `=== ПЕТРОВИЧ (ВВОД) ===`
- `=== КОЛЯ-AVITO (SEO-ЯДРО) ===`
- `=== АРТЁМ-AVITO (КОНКУРЕНТЫ) ===`
- `shared/legis24-site-context.md`

## Структура описания

1. **Крючок** — боль + срок 24 часа (1–2 предложения)
2. **Что входит** — буллеты 4–6 пунктов
3. **Цена и кейс** — цифра с сайта, один кейс
4. **География** — вся РФ, удалённо
5. **CTA** — order@advokat-vsem.ru + https://advokat-vsem.ru

Объём: **1500–3000** знаков.  
Тон: B2B, уверенно, без «гарантируем победу».
