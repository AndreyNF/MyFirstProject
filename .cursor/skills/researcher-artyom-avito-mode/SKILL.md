# Skill: researcher-artyom-avito-mode

Режим **Артёма** для пайплайна Avito.

## Задача

**Конкурентная разведка** объявлений на Avito в нише и регионе (веб, не API).

## Метод

1. WebSearch: `{ниша} site:avito.ru {регион}` и вариации
2. WebFetch 3–5 релевантных карточек (если доступны)
3. Таблица: заголовок, цена, сильные/слабые стороны, длина описания

## Выход

```markdown
=== АРТЁМ-AVITO (КОНКУРЕНТЫ) ===
Статус: ✅ ГОТОВО

## Обзор рынка
...

## Таблица конкурентов
| # | Заголовок | Цена | Что цепляет | Пробел |
...

## Рекомендации для Legis24
- Отстройка: ...
- Ценовой якорь: ...
- Чего избегать в заголовке: ...
```

## Запреты

- Не писать финальное описание
- Не вызывать Wordstat (Коля)
