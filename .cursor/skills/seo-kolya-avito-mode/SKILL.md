# Skill: seo-kolya-avito-mode

Режим **Коли** для пайплайна Avito (не лонгрид).

## Задача

Собрать **семантическое ядро для одного объявления**: кластеры, частотность, мета-поля для заголовка/первых строк описания.

## MCP (обязательно)

Сервер **Kovcheg**:

1. **10–15×** `wordstat_get_top_requests` — разные семена из блока Петровича
2. **1×** `wordstat_get_dynamics` — главный ВЧ-запрос
3. **1×** `wordstat_get_regions` — регион из ввода (или Россия)

Не придумывать частотности без ответа MCP.

## Выход (маркер)

```markdown
=== КОЛЯ-AVITO (SEO-ЯДРО) ===
Статус: ✅ ГОТОВО

## Вызовов Wordstat
...

## Топ-кластеры (для заголовка и первого абзаца)
| Кластер | Главный ключ | Показы | В заголовок? |
...

## Рекомендации
- Заголовок (черновик ≤50): ...
- LSI для описания: ...
- Минус-слова / не использовать: ...

## Передача Жене
УТП: ...
Боль: ...
```

## Запреты

- Не писать полное описание объявления (это Женя).
- Не искать конкурентов Avito (это Артём).
