### Ст. 227 и 230 Закона о банкротстве (127-ФЗ)

**Глава XI, § 2** — банкротство отсутствующего должника (упрощённый трек: ст. **227–229** + **230**).

**Ст. 227 — кто и когда может подать заявление**  
- Кредитор (в т.ч. **ФНС**) или иные уполномоченные лица — при отсутствии должника / невозможности установить местонахождение **руководителя** (п. 1).  
- Отдельные правила для заявления **самого** юрлица и уполномоченных органов при наличии средств на финансирование процедур (п. 2).  
- **Бремя доказывания** «отсутствия» по п. 1 ст. 227 — на **заявителе** (ст. 65 АПК; практика INTELLECT, Kommersant).

**Ст. 230 — самодостаточные основания упрощёнки** (без п. 1 ст. 227)  
Параграф применяется, если **документально** подтверждено **любое** из:  
1) имущество **заведомо не покрывает** судебные расходы по делу о банкротстве;  
2) **нет операций** по счетам **12 месяцев** до даты заявления о банкротстве;  
3) **иные признаки** прекращения предпринимательской/иной деятельности.

**П. 22 Обзора ВС № 3 (2021)** (дело **А04-8832/2019**, «Андротранс»): основания ст. 230 **самодостаточны**; достаточно **одного** критерия. Нижестоящие суды в «Альфа-Тех» опирались именно на эту линию — ВС фактически **сузил применение** формальных критериев при **противоречивой** фактической картине.

**Контраст с «Альфа-Тех»:** наличие формального основания по ст. 230 **не освобождает** суд от проверки **реального** прекращения деятельности и **причин** отсутствия банковских операций.

### Мотивировка ВС (тезисы для Жени / аргументация ARB)

1. **Нет однозначного вывода** о недостаточности активов: ФНС сначала заявила об **отсутствии имущества**, затем сообщила об активах **18,6 млн руб.**  
2. **Деятельность не прекращена:** отчётность, коммунальные платежи, процессуальная активность, **частичное погашение** долга.  
3. **Блокировка счетов ФНС** ≠ отсутствие операций по смыслу **ст. 230** (критерий 12 месяцев **не соблюдён** в доводах заявителя).  
4. **Один сотрудник**, нулевая отчётность, микроактивы — **недостаточны** сами по себе.  
5. **Правовых оснований** для банкротства по упрощёнке отсутствующего должника **не было**; выводы нижестоящих судов **нельзя признать правомерными**.  
6. **Цель закона** — восстановление платежеспособности → **приоритет реабилитационных процедур** (**наблюдение**), **п. 64 Постановления Пленума ВАС/ВС **№ 40** от **17.12.2024**.  
7. Даже при признаках неплатежеспособности суд **может отказать** во введении банкротства, если должник докажет **временный** характер затруднений (RVZ).  
8. При **новом рассмотрении** суд обязан проверить основания для **наблюдения** и возможность погашения долга **без** банкротства ([263944](https://pravo.ru/news/263944/)).

**Kommersant (8624380) — экспертный слой для статьи:**  
- бремя доказывания упрощёнки — на **кредиторе** (Азат Ахметов, Orchards);  
- спорный вопрос — **стандарты доказывания** «отсутствия» при работающем бизнесе, аутсорсинге, платежах через третьих лиц;  
- ожидание **уточнения** практики ВС по признакам отсутствующего должника (контекст к майскому делу).

### Практические последствия

**Для должника (директор / собственник)**  
- При **блокировке счетов** — фиксировать **альтернативные платежи** (третьи лица, касса, взаимозачёты) и **текущую деятельность** (отчётность, договоры, коммуналка, судебное участие).  
- Возражения на заявление ФНС: **несоответствие** ст. 230, **противоречие** данных налоговой об активах, запрос **наблюдения** вместо упрощёнки.  
- Аргумент **временных** финансовых трудностей + план погашения (в связке с п. 64 Пленума № 40).

**Для ФНС / иных кредиторов**  
- Формальные признаки (нулевая отчётность, отсутствие движения по счетам) **ломаются**, если счета **заблокированы** должником же (налоговым органом).  
- Нужна **согласованная** позиция по **активам** (бухотчётность, инвентаризация, арест) — иначе риск отмены в ВС.  
- Упрощёнка — **исключение**; при признаках работающей компании готовить доказательства **ст. 230** в связке с **фактическим** прекращением деятельности, а не только «техничкой».

**Для арбитражного управляющего / кредиторов по делу**  
- При отмене — вероятность **наблюдения** и обычного трека (сроки, собрание, оспаривание сделок).  
- См. ниже **307-ЭС25-13338** — при конкурсном производстве управляющему **недостаточно** % отклонения цены от рыночной.

**Риски для контрагентов**  
- Попытки ФНС «закрыть» работающее ООО через упрощёнку могут повторяться при крупном налоговом долге; контрагентам важна **публичная** отчётность и отсутствие признаков «технической» фирмы в материалах проверки.

### Связанное определение 17.04.2026 № **307-ЭС25-13338** (кратко)

**Дело:** № **А56-96799/2023** (оспаривание **купли-продажи квартиры** должником перед банкротством).  
**Источник:** [обзор ЮКО, апрель 2026](https://yko.ru/obzor-praktiki-verhovnogo-suda-rossijskoj-federacii-po-nalogovym-korporativnym-sporam-i-bankrotstvu-za-aprel-2026-goda/).

**Позиция ВС (4 тезиса):**  
1. Для **подозрительной** сделки (**ст. 61.2**) **недостаточно** формального % отклонения цены от рыночной — нужна **совокупная** оценка обстоятельств и **контекста** отношений сторон.  
2. Цена **5 млн руб.** согласована сторонами, **выше кадастровой** → не «существенно заниженная».  
3. Суды **не оценили** довод о **злоупотреблении** должником; последствия недействительности **нельзя** возлагать на добросовестного ответчика.  
4. Ограничение анализа только **процентом** отклонения — нарушение правила оценки подозрительных сделок → отмена.

**Стыковка с «Альфа-Тех»:** один абзац для управляющих — ВС в 2026 последовательно требует **фактической**, а не формальной квалификации (упрощёнка / оспаривание). **Не раздувать** блок «оспаривание» (интент страницы — упрощёнка + ФНС + защита должника).
