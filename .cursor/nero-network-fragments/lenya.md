### Что исправить Юре

1. **Critical — починить HTML после блока FAQ**  
   - С ~второго вопроса FAQ (`Обязателен ли ответ на иск?`) `itemprop="text"` обрывается («осовестных*»»), дальше в поток попадает контент из раздела про компенсацию.  
   - В конце страницы в `<ul>` / `<pre>` торчит **невалидный JSON** (`FAQPage`, `Question`…) — пользователи и краулеры видят «мусор».  
   - Закрыть `</div></section>` для `#b2-faq`; вынести FAQ в **валидный** `application/ld+json` (или целые microdata-пары Question/Answer на все 6+ вопросов).

2. **Critical — убрать дубль hero и починить SVG**  
   - Hero продублирован (второй блок с тем же H1 ~стр. 675+).  
   - В первом hero SVG обрыв на `font-weight=amily:` — после этого вставлен повтор `<style>`/hero. Оставить **один** hero, H1 в hero сделать **`<p class="…">` или `<h2>`**, единственный **H1** — `entry-title` (или наоборот, но строго один H1).

3. **High — добавить `<meta name="description">`**  
   - Скопировать/адаптировать из `og:description` (150–160 симв., с «ответ на иск», «возражение», «компенсация», «товарный знак»). Без этого Яндекс/Google часто собирают сниппет сами, хуже CTR.

4. **High — укоротить `<title>`**  
   - Цель ≤60–65 симв. до бренда:  
     `Иск о защите ИС против вас: план ответа, сроки, возражение`  
   - Бренд «Legis 24» — через разделитель в конце или в шаблоне Yoast отдельно.

5. **High — усилить перелинковку в теле**  
   - Добавить 4–6 контекстных ссылок на slug из ядра Коли: «возражение на иск», «срок ответа на иск», «суд по ИС», «претензия ТЗ» (если страницы есть на `.online`). Сейчас перелинковка почти только на 3 IP-URL.

6. **Medium — schema для GEO**  
   - Добавить `@type: Article` (author, datePublished/Modified, headline = H1).  
   - FAQ — отдельный блок `FAQPage` в JSON-LD **после** исправления HTML (все Q/A валидны).

7. **Medium — mobile viewport**  
   - Убрать `maximum-scale=1.0, user-scalable=0` → `width=device-width, initial-scale=1`.

### Приоритет

- **Critical:** сломанный FAQ + сырой JSON в DOM; дубль hero + битый SVG; множественные H1  
- **High:** нет `meta description`; длинный title; слабая внутренняя перелинковка  
- **Medium:** нет Article в schema; жёсткий viewport; sidebar «Свежие записи» — налоговые статьи, не IP-хаб
