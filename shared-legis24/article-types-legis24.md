# Типы статей Legis24 (для Коли, Артёма, Жени)

Каждый cron-слот публикует **один** тип. Precheck выбирает первую незавершённую строку очереди с этим типом.

## Слот → тип

| Слот | UTC (МСК) | Код типа | Название |
|------|-----------|----------|----------|
| 1 | 03:00 (06:00) | **ARB** | Арбитраж |
| 2 | 09:00 (12:00) | **IP** | Защита интеллектуальной собственности |
| 3 | 15:00 (18:00) | **UG** | Уголовное право |

Cron в Cursor Automation: `0 3,9,15 * * *`

## Тип 1 — ARB (арбитраж)

**Угол:** корпоративные и экономические споры, арбитраж при банкротстве, споры с кредиторами/контрагентами, подсудность, сроки, доказательства, первая линия защиты.

**Семантика (примеры):** арбитражный спор, арбитражный суд, иск в арбитраже, оспаривание сделки арбитраж, представитель в арбитраже.

**CTA:** консультация по арбитражному спору / стратегии в суде.

## Тип 2 — IP (интеллектуальная собственность)

**Угол:** товарный знак, бренд, нарушение ИС, защита прав правообладателя, **ответ на иск** если на вас подали по защите ИС, претензия, судебная защита, особенности доказательств.

**Семантика:** защита товарного знака, иск по интеллектуальной собственности, нарушение товарного знака, ответ на иск по ИС, регистрация знака, взыскание компенсации.

**CTA:** консультация по защите бренда / ответу на иск по ИС.

## Тип 3 — UG (уголовное право)

**Угол:** уголовные риски гражданина и бизнеса (мошенничество, злостное уклонение, легализация), граница гражданского и уголовного, поведение при проверках и возбуждении дела, защита на стадии доследственной проверки/суда.

**Семантика:** уголовная ответственность за долги, ст. 159, 177 УК, защита по уголовному делу, адвокат по уголовным делам.

**CTA:** консультация по уголовным рискам / защите в уголовном деле.

## Масштаб

- **3 статьи/день** — штатный режим (3 cron-слота, интервал 6 ч).
- **До ~300/день** пайплайном Nero (Task × лонгрид × hero) **недостижимо** без десятков параллельных automation и упрощённого шаблона. Для высокого объёма нужен отдельный «лёгкий» конвейер (короткий текст, без hero/canvas).
