# MigSwap BLOG — контракт написания статей

## Вход

- `memory/topics/blog-topics.md` — карточка темы
- `memory/brief/site-brief.md`, `fact-bank.md`, `conversion-map.md`
- `research-notes.md` + `research-notes-gate.json` со status PASS

## Объём

**8 500–9 500 символов** (plain text без тегов).

## HTML

Разрешённые теги: `h2`, `h3`, `p`, `b`, `i`, `a`, `ul`, `ol`, `li`, `blockquote`, `table`.

## Ссылки

- 6–10 ссылок на https://t.me/MigSwap_bot
- 2–4 ссылки на https://migswap.com

## Запреты (title, H2, лид, якоря)

«купить USDT», «курс BTC», доходность, прогноз курса, лицензия ЦБ, обход 115-ФЗ.

## Структура

1. Лид с болью читателя
2. blockquote с выжимкой
3. H2-секции по outline
4. Один технический абзац про тикеры и сети
5. FAQ
6. Дисклеймер: риски + 282-ФЗ + сверка условий на migswap.com

## Факты

Только из fact-bank, migswap.com, t.me/MigSwap_bot. Не выдумывать лимиты и сроки.

## Выход

`article.html`, `article.meta.json`
