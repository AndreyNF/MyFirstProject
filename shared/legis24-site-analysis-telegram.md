## УТП для Telegram

1. **Скорость** — не «консультация», а готовый документ/стратегия за сутки  
2. **Фикс-прайс** — прозрачная таблица на главной  
3. **B2B** — аутсорс для юристов + партнёрка для бухгалтеров (до 30%)  
4. **Контент-машина** — 25+ лонгридов на сайте → бесконечные темы для постов

## Структура главной (воронка)

```
Хук (24 ч, 107 млн снижено) → Услуги → Цены ФНС → Процесс 3 шага

```
